
# sid_stock_cfg

Módulo ancla para fijar `xml_id` estables (`ir.model.data`) sobre registros ya existentes de configuración.

Incluye referencias estables para `stock.location`, `stock.location.route`, `stock.picking.type`, `stock.warehouse`, `documents.folder`, y otros registros usados por módulos personalizados.

También incorpora:
- `sid_stock_cfg.stock_picking_type__mad__outgoing__seq2__entrega_a_cliente__c1`
- `sid_stock_cfg.res_partner__almacen_sidsa_alcobendas__c1`
